# Handoff: 개발자의 잡화점 (A Little Shop of Worries)

익명으로 고민을 접수받고 → 운영자가 선정·게시하고 → 다른 개발자들이 "해결편지(처방)"를 보내고 → 운영자가 좋은 편지를 모아 SNS에 올리는, 타이프라이트(typewrite.co)류의 커뮤니티 서비스.

## 이 폴더에 든 것
- `prototype/개발자의 잡화점.dc.html` — **디자인 레퍼런스(HTML 프로토타입)**. 그대로 배포하는 코드가 아니라, *의도한 화면/동작/색·타이포*를 보여주는 시안입니다. 실제 구현은 아래 타깃 스택에서 **이 시안을 재현**하는 작업입니다. (브라우저로 바로 열림. `support.js`는 런타임 헬퍼.)
- `CLAUDE_CODE_PROMPTS.md` — **Claude Code에 그대로 붙여넣는 페이지별 프롬프트.** 이 핸드오프의 핵심.
- `SPEC.md` — 기능/로직/데이터 구조 명세(원본 스펙).
- `DESIGN_TOKENS.md` — 색·폰트·베벨·편지지 등 디자인 토큰 전체.

## 권장 스택
Next.js (App Router) + Supabase(Postgres). 다른 스택도 구조는 동일하게 적용 가능. 기존 코드베이스가 있으면 그쪽 패턴/라이브러리를 따르고, 없으면 위 스택으로 새로 만든다.

## Fidelity
**High-fidelity.** 색·타이포·간격·인터랙션이 확정된 시안입니다. UI는 `DESIGN_TOKENS.md` 값으로 픽셀에 가깝게 재현하세요. 단 정적 일러스트(차양·우유통)는 CSS 도형으로 그려져 있으니 그대로 옮기거나 동등하게 재현하면 됩니다.

## 화면(3종)
| 경로 | 공개 | 역할 |
|---|---|---|
| `/submit` | 공개 | 고민 접수 — "우유통에 넣기" |
| `/solve` | 공개 | 현재 게시중(`published`) 고민 1건에 해결편지 작성 |
| `/admin` | 비번 게이트 | 5탭 상태관리 + 마감 탭 편지 정리(모아보기) |

## 컨셉/톤
레트로 데스크톱 프로그램(메모장/95 창) 골격 + 잡화점 감성 10%(틸·크림 색감, 차양 줄무늬, "영업중" 상태바, 손글씨 편지지, 우유통 투입 모티프). 나미야 잡화점 *분위기*만 참고하되 표지/일러스트를 모방하지 않음.

## 구현 순서
`CLAUDE_CODE_PROMPTS.md`의 **프롬프트 0(셋업) → 1(/submit) → 2(/solve) → 3(/admin)** 순으로 한 프롬프트씩 Claude Code에 전달하세요. 각 프롬프트는 단독 실행 가능하도록 토큰/스키마를 포함합니다.
